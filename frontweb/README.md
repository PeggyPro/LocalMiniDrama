# web2 - 单页 AI 视频生成

与现有 `web` 并列的前端项目，实现**单页**从故事到成片的完整流程，对接现有 Node 后端 `backend-node`。

**包版本：** `1.2.9`（与仓库根目录 [CHANGELOG](../CHANGELOG.md) 一致）

## 功能流程

1. **本集创作**：全剧背景在各集间共享；每集单独填写标题、创作要求与正文，可选择参考上一集。新建集为空白，生成只更新当前集。
2. **剧本编辑**：保存只更新当前集，正文中的章节标题不会自动拆成多集。普通模式和画布模式使用同一份分集草稿，切集或刷新后仍保留；服务器版本发生变化时先处理冲突。
   - **整剧批量生成**：在项目详情中操作，提交前明确确认生成集数和替换范围。
   - **小说/剧本导入**：明确选择导入当前集、追加新集或替换分集列表；批量导入在服务器保存成功后才清空预览。
   - 每集有独立分镜和制作进度，角色身份与全剧素材库可复用。修改剧本后保留原有制作素材，需核对后继续制作。
3. **角色生成**：AI 生成角色列表 → 每个角色可「AI 生成」形象（使用下方配置的图片模型）
4. **道具生成**：从剧本提取 / 手动添加 → 每个道具可「AI 生成」图片
5. **场景生成**：从剧本提取场景 → 每个场景可「AI 生成」图片
6. **分镜生成**：根据当前集生成分镜
7. **视频配置**：分辨率、配乐、音效、画质、字幕、水印；**AI 模型配置**（图片生成模型、视频生成模型）
8. **生成视频**：提交合成任务

每集分别保存三项：`source_text` 是完整的**本集原文**，`description` 是**创作/改编要求**，`script_content` 是导入或生成的**剧本**。

**批量原文导入后生成**：在项目详情的“批量导入剧集”中粘贴正文或选择 TXT，内容类型默认“本集原文”；按章节预览并确认追加后，进入各集填写创作要求，再生成本集剧本。原文完整保留在 `source_text`；选择“已有剧本”则只导入 `script_content`，不自动填充另一类正文或创作要求。导入仅追加新集，失败时保留预览以便重试。

## 运行

```bash
# 安装依赖
npm install

# 开发（默认端口 3013，代理到后端 5680）
npm run dev

# 构建
npm run build
```

请先启动 `backend-node`（如 `http://localhost:5680`），并确保 `vite.config.js` 中 proxy 的 target 与后端一致。

## 技术栈

- Vue 3 + Vite
- Element Plus
- Pinia
- Vue Router
- Axios
- 纯 JavaScript（无 TypeScript）
